# Auto Clicker

macOS 向け個人用オートクリッカー。GUI 付きでホットキーから操作できます。

## 動作環境

- macOS
- Python 3.14（Homebrew）
- python-tk@3.14

## セットアップ

### 1. 依存ライブラリのインストール

```bash
cd autoclicker
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

### 2. アクセシビリティ権限の付与（初回のみ）

マウス操作に必要です。

1. **システム設定** → **プライバシーとセキュリティ** → **アクセシビリティ**
2. **ターミナル** をリストに追加してチェックを入れる

## 起動

```bash
.venv/bin/python autoclicker.py
```

## 画面の各設定

### クリック間隔

クリックする間隔を秒単位で指定します。

| 設定値 | クリック速度 |
|---|---|
| `0.01` | 1秒に100回 |
| `0.1` | 1秒に10回 |
| `1.0` | 1秒に1回 |

### マウスボタン

`左クリック` / `右クリック` / `中クリック` から選択します。

### クリック位置

| モード | 動作 |
|---|---|
| **現在のカーソル位置** | クリック中のカーソル位置をそのままクリックし続ける |
| **固定位置** | 指定した X・Y 座標を常にクリックする |

**「現在位置を取得」ボタン**を押すと、2秒後のカーソル位置を自動的に X・Y に入力します。

## ホットキー

| キー | 動作 |
|---|---|
| `F9` | 開始 / 停止の切り替え |
| `F10` | アプリを終了 |
| マウスを画面左上隅に移動 | 緊急停止（フェイルセーフ） |

## 使い方の例

### 特定の場所を連打する

1. 「現在位置を取得」ボタンを押す
2. 2秒以内にクリックしたい場所にカーソルを移動する
3. 「固定位置」が自動選択されて座標が入力される
4. クリック間隔・ボタンを設定する
5. `F9` で開始

### カーソルを動かしながら連打する

1. 「現在のカーソル位置」を選択する
2. クリック間隔・ボタンを設定する
3. `F9` で開始 → カーソルを動かすとその場所をクリックし続ける

## 注意事項

- **フェイルセーフ機能**：クリック中にマウスを画面の左上隅に移動すると即座に停止します
- アクセシビリティ権限がないとクリックが動作しません
- 他のアプリへの過度な自動操作はそのアプリの利用規約に違反する場合があります
